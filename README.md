# Ramya Ravikumar | Portfolio Website

My personal portfolio: resume, projects, and (coming soon) games built with public APIs.

**Live site:** https://ramyaravikumar22.github.io/web101_Ramya_Ravikumar/

## About
Integration Specialist with 4+ years of experience delivering SaaS and API integrations, technical troubleshooting, and client onboarding. I'm growing into front-end development and building projects to show it.

## What's on the site
- **About**: short bio and skills
- **Projects**: integration and documentation work, plus this site
- **Games**: browser games powered by public APIs (in progress)
- **Resume**: experience, education and certifications
- **Contact**: GitHub and email

## Built with
- HTML5
- CSS3 (flexbox, grid, responsive layout)
- Hosted on GitHub Pages

## Project structure
```
index.html          # the whole site (one page)
css/style.css       # styling
images/profile.jpg  # profile photo
```

## Run it locally
1. Clone the repo:
   ```bash
   git clone https://github.com/ramyaravikumar22/web101_Ramya_Ravikumar.git
   cd web101_Ramya_Ravikumar
   ```
2. Open `index.html` in your browser, or in VS Code use the **Live Server** extension.
